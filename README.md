# KHCM Traffic Analyzer

도로용량편람(2013)에 따른 도시 및 교외간선도로 분석용 Windows 데스크톱 프로그램입니다.

## 주요 기능

- 현황·사업 미시행·사업 시행·개선대책 시나리오별 구간 분석
- 평균통행속도 및 서비스수준(LOS) 산정
- Microsoft Excel 셀·범위의 교통량 합계와 PHF 연결, 주소식 직접 입력 및 일괄 경로 변경
- 교차로 분석 정리 Excel의 서비스수준 참고값 일괄 불러오기와 구간별 제한속도 참고값 저장
- 분석 탭 메모, Ctrl+Z 되돌리기와 프로젝트에 저장되는 변경 기록
- 보고서용 표 및 부록용 세부 계산결과
- 구간 연결 관계도와 입력표 간 양방향 구간 선택
- GitHub Releases 기반 자동 업데이트 확인·다운로드·무결성 검증·재설치

## 설치 및 실행

현재는 도시 및 교외간선도로 분석을 제공하며, 향후 교차로 분석 등 도로용량편람 기반 모듈을 같은 프로그램에 확장할 예정입니다.

일반 사용자는 [Releases](https://github.com/OutsiderStudent/khcm-traffic-analyzer/releases)에서 장치에 맞는 최신 EXE를 내려받아 실행합니다. 일반 Intel·AMD Windows PC는 `x64`, Snapdragon 기반 Surface 등 Windows ARM 장치는 `arm64` 파일을 사용합니다.

개발 실행:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .[dev]
.\.venv\Scripts\python.exe -m arterial_analysis
```

## 시험

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 배포

`v1.3.0`처럼 버전 태그를 GitHub에 푸시하면 Windows x64와 ARM64 실행파일을 각각 빌드하고 GitHub Release에 첨부합니다. 프로그램은 시작 후 최신 Release를 비동기로 확인하며, 새 버전이 있을 때 현재 장치 아키텍처에 맞는 파일을 내려받아 검증하고 교체합니다.

## 주의

- Microsoft Excel 연동 기능은 Windows용 Microsoft Excel과 `pywin32`가 필요합니다.
- 분석 결과는 입력자료와 적용 조건에 따라 달라지므로 최종 성과품 작성 전 세부 계산결과를 검토해야 합니다.
- 도로용량편람 원문 및 사용자가 작성한 프로젝트·Excel 파일은 이 저장소에 포함하지 않습니다.


### 2026 관계도 (1.10.0)

설정 → 분석 기준 → 2026 도로용량편람 (베타)에서 사용합니다. 기본 분석 기준은 2013입니다.

- F6 또는 관계도 버튼으로 열고 교차로를 추가합니다. Ctrl+클릭 또는 연결 버튼으로 두 교차로를 순서대로 선택하면 양방향 구간이 생성됩니다.
- 선 양쪽의 반쪽 화살표는 우측통행 기준입니다. 각 방향의 지체·용량은 그 방향의 종점 교차로 값입니다.
- 원을 끌어 위치를 바꾸고, 더블클릭으로 이름 또는 구간 정보를 수정합니다. 우클릭으로 교차로 삽입·삭제 및 연결 삭제를 실행합니다.
- 여러 연결을 하나의 간선도로로 분석하려면 경로 선택 → 교차로를 진행 순서대로 클릭 → 경로 확정을 사용합니다. 반대 방향 경로도 함께 만들어집니다.
- 회전 이동류는 도로망에 기록할 수 있지만 편람의 직진 간선도로 분석으로 계산하지 않습니다. 신설 교차로의 지체·용량은 자동 추정하지 않습니다.
- 기존 입력표를 관계도로 가져올 수 있습니다. 횡단보도·제한속도 변경지점이 포함된 기존 경로는 입력표에서 유지합니다.
- 연결된 경로의 기하구조를 바꾸면 구간 전체 조사값이 초기화되고 경계 확인이 해제됩니다. 교차로 파일 자동 연동은 추후 지원합니다.
- 저장된 결과는 입력 변경 후 재분석해야 합니다. 미입력 항목을 클릭하면 해당 입력칸으로 이동합니다.
- 임시 저장은 원본과 별도입니다. 프로젝트 → 임시 저장 복구에서 복구하고 확인 후 정식 저장하세요.
